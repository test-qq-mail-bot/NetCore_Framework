# 解决方法（常见问题排查）

## 1. 启动报「端口被占用 / 程序显示运行但网页打不开」

- 框架默认监听 `0.0.0.0:8080`。若 8080 被占用（如华为 AgileController），框架会自动顺延到 +1 ~ +20 的可用端口，并在控制台打印实际地址。请按控制台提示的地址访问。
- 若浏览器经 `127.0.0.1` 访问却命中其他进程（`404` 或旧页面）：这是因为 Windows 下 `0.0.0.0` 与 `127.0.0.1` 绑定语义不同。框架已对通配 host 同时校验两个地址，正常情况不会出现；若仍异常，手工修改 `config/core.yaml` 的 `server.port` 为其他端口。

## 2. 默认密码登录失败

- 正确默认密码为 `Admin@123!`（旧版 `Huawei@123` 已失效，代码三处硬编码均为新密码）。
- 若仍失败，检查 `config/user_config.yaml` 的 `auth.password_hash`。框架在哈希为空时会用默认密码重建哈希；若损坏，删除 `user_config.yaml` 让其重新生成（**会重置为默认密码，但保留其他配置**）。
- 临时重置：在 `user_config.yaml` 的 `auth` 下加入 `password_plain: "你的新密码"`，启动一次后框架会用新密码覆盖哈希并自动移除该字段退出，移除该字段再正常启动。

## 3. 插件已显示在菜单，但调用接口返回 404

- 根因：运行期通过「插件列表」启用插件后，路由未挂载。
- 解决：框架已通过 `mount_new_routes()` 修复；若仍 404，重启框架即可（启动期 `lifespan` 会调用 `mount_routes` 全量挂载）。

## 4. 插件加载失败 / 菜单不显示

- 查看日志 `data/logs/` 下当天日志，搜索 `插件 xxx 加载失败`。
- 常见原因：插件目录缺少 `plugin.py`、未继承 `BasePlugin`、依赖未安装、`on_load()` 抛异常。
- 框架采用故障隔离：单个插件失败不影响其他插件与核心功能。

## 5. HTTPS 浏览器提示「不安全」

- 使用自签名证书时属正常现象。可上传受信任的自定义证书（`.crt/.pem` + `.key`）到「基础设置 → HTTPS」消除提示。
- 远程访问需确保证书 SAN 包含访问 IP 或域名（配置 `https.domain`，多个用逗号分隔；也可留空让框架枚举网卡 IP）。

## 6. 审计日志过大 / 想清理

- Web 后台「日志中心 → 审计日志」可清理全部审计记录（`DELETE /api/logs/audit/clean`）。
- 导出审计日志上限 `AUDIT_EXPORT_MAX=20000` 条；超出会在响应头标 `X-Audit-Truncated: true` 并追加截断说明。

## 7. 前端白屏（生产构建）

- 多为前端模板编译错误。重点排查：
  - Vue 修饰符事件无 handler（如 `@click.stop` 无方法）→ 需 `.stop` 等使用 `withModifiers` 时传入 `undefined` 会崩溃。
  - 模板绑定值以 `.` 开头（如 `:accept=".csv"`）会被当表达式求值 → 改用 `:accept="'.csv'"` 或静态属性。
  - 框架全局 Vue 是 Vue 3，**禁止使用 `this.$set` / `Vue.set`**（点击抛 not a function），响应式用直接赋值。
  - 插件前端 JS 改动后可通过 `frontend-manifest` 的 `?v=<mtime>` 自动失效缓存。

## 8. 客户端断开时控制台刷 ConnectionResetError

- Windows 下客户端正常断开会触发 `ConnectionResetError(10054)`，属正常噪声。框架已在运行的事件循环上挂载异常处理器过滤此类异常，不会写入业务日志。

## 9. 升级后插件数据丢失

- 不应发生。框架资源提取采用「合并拷贝 + 跳过 data/logs/__pycache__」策略，用户数据持久保留。
- 若发现丢失，确认是否曾手工 `rm -rf` 过插件目录，或检查是否被安全删除机制拦截了写入。

## 10. 通知发送失败

- 检查 `config/notify.yaml` 对应渠道 `enabled` 是否 `true`、Webhook/SMTP 凭据是否正确。
- 渠道配置即时生效，可用 Web 后台「通知管理 → 测试」验证。
- 频率限制：默认同一渠道最小间隔 60 秒，避免轰炸。
