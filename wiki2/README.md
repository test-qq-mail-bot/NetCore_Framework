# NetCore Framework 文档集（wiki2）

本目录为 NetCore Framework 底层框架的开发者与使用文档，按主题拆分：

| 文档 | 内容 |
| --- | --- |
| [教程](教程.md) | 安装部署、首次启动、基础配置、构建与发版、插件安装 |
| [程序逻辑](程序逻辑.md) | 启动流程、插件发现与加载、请求管线、资源提取、鉴权与会话 |
| [解决方法](解决方法.md) | 常见问题排查（端口冲突、登录失败、插件 404、HTTPS、审计等） |
| [插件制作过程](插件制作过程.md) | 从零开发一个插件的完整流程与契约 |
| [API 文档](API文档.md) | 框架内置 REST API（认证 / 安全 / 通知 / 审计 / 系统 / 插件） |

> 运行期内置文档（使用说明、UI 规范、插件开发指南等）位于仓库根 `wiki/` 目录，由 `wiki_docs` 插件在 Web 后台「使用文档」菜单提供；本 `wiki2/` 为仓库级源码文档。
