# 数通配置卫士 - 网络拓扑 - 拓扑路线端口描述展示规范

> **文档版本**：v1.0
> **适用模块**：数通配置卫士 → 网络拓扑 → 拓扑图 → 拓扑路线
> **文档性质**：前端开发实施规范
> **最后更新**：2026-08-13

---

## 一、概述

### 1.1 目的

规范网络拓扑图中，当两台设备之间存在物理链路时，**链路端口标签的排版方式与视觉呈现**。根据设备间的空间排列关系（垂直、水平、对角），端口描述需采用不同的内嵌策略，确保拓扑图在任意布局下均保持高可读性。

### 1.2 核心原则

| 序号 | 原则 | 说明 |
| :---: | :--- | :--- |
| 1 | **方向自适应** | 端口标签的排列方向必须跟随链路走向，禁止统一使用水平或垂直排列 |
| 2 | **字体描边必选** | 所有端口标签必须添加描边/阴影，防止与链路线条重叠导致不可读 |
| 3 | **三段式结构** | 链路始终划分为「源端段 → 物理连接段 → 目的端段」三部分 |
| 4 | **降级兼容** | 图形渲染为主，纯文本导出为降级方案，两种模式均需实现 |

---

## 二、模式分类总览

| 模式编号 | 排列方式 | 模式名称 | 英文标识 | 标签排版策略 |
| :---: | :---: | :--- | :--- | :--- |
| 模式A | 上下排列 | 垂直链路端口竖排内嵌 | `Vertical Stacked` | 端口文字逐字符纵向堆叠，沿Y轴分布 |
| 模式B | 左右排列 | 水平链路端口内嵌 | `Horizontal Inline` | 端口文字单行水平串联，沿X轴分布 |
| 模式C | 斜向排列 | 对角链路端口斜排内嵌 | `Diagonal Staggered` | 端口文字沿链路角度旋转/阶梯错位分布 |

---

## 三、模式A：垂直链路端口竖排内嵌 (Vertical Stacked)

### 3.1 触发条件

当源设备与目的设备在拓扑画布上的 **X轴坐标相同（或差值 ≤ 阈值）**，且 **Y轴坐标不同** 时，判定为垂直排列。

> 阈值建议：`|ΔX| ≤ 20px`（可根据画布缩放比例动态调整）

### 3.2 排版规则

- 端口名称的每个字符**逐行纵向堆叠**（或按固定宽度分段折行）
- 标签位于链路线条的**左侧或右侧**（默认右侧），与线条保持 `8px` 间距
- 源端口标签靠近源设备侧，目的端口标签靠近目的设备侧
- 物理连接段（中段链路）不放置标签

### 3.3 ASCII 示意图

```TEXT
       [ 垂直模式：纵向堆叠 ]

          'A设备'

             |
             |  <-- 上段链路（源端段）
             |
           G 1
           / 0
           / 1   <-- 源端口 (竖排/分段内嵌)

             |
             |  <-- 中段链路 (物理连接)
             |
           G 1
           / 0
           / 1   <-- 目的端口 (竖排/分段内嵌)

             |
             |  <-- 下段链路（目的端段）
             |
          'B设备'
```

### 3.4 视觉要求

| 属性 | 值 |
| :--- | :--- |
| 字体方向 | 纵向（逐字符换行 或 `writing-mode: vertical-rl`） |
| 字体描边 | `-webkit-text-stroke: 1px #FFFFFF` |
| 文字阴影 | `text-shadow: 0 0 3px rgba(255,255,255,0.9)` |
| 标签与线条间距 | ≥ `8px` |
| 标签字号 | `12px`（跟随画布缩放） |
| 标签颜色 | `#333333`（深色文字 + 白色描边） |

---

## 四、模式B：水平链路端口内嵌 (Horizontal Inline)

### 4.1 触发条件

当源设备与目的设备在拓扑画布上的 **Y轴坐标相同（或差值 ≤ 阈值）**，且 **X轴坐标不同** 时，判定为水平排列。

> 阈值建议：`|ΔY| ≤ 20px`

### 4.2 排版规则

- 端口名称**单行水平排列**，内嵌于链路线条上方或下方
- 源端口紧贴源设备出口侧，目的端口紧贴目的设备入口侧
- 物理连接段（中段）用加粗/虚线表示，不放置标签
- 所有元素在同一水平基线上，形成「设备—端口—链路—端口—设备」的串联结构

### 4.3 ASCII 示意图

```TEXT
       [ 水平模式：单行串联 ]

'A设备' --- 'G1/0/1' ============== 'G1/0/1' --- 'B设备'
   ^           ^            ^            ^           ^
   |           |            |            |           |
 源设备      源端口       物理链路      目的端口     目的设备
```

### 4.4 视觉要求

| 属性 | 值 |
| :--- | :--- |
| 字体方向 | 水平（默认） |
| 字体描边 | `-webkit-text-stroke: 1px #FFFFFF` |
| 文字阴影 | `text-shadow: 0 0 3px rgba(255,255,255,0.9)` |
| 标签位置 | 线条上方 `4px` 或下方 `4px`（默认上方） |
| 标签字号 | `12px`（跟随画布缩放） |
| 标签颜色 | `#333333` |
| 物理链路样式 | 加粗实线 `stroke-width: 3px` 或双线 `═══` |

---

## 五、模式C：对角链路端口斜排内嵌 (Diagonal Staggered)

### 5.1 触发条件

当源设备与目的设备在拓扑画布上的 **X轴和Y轴坐标均不同**，且差值均超过阈值时，判定为斜向（对角线）排列。

> 判定条件：`|ΔX| > 20px` **且** `|ΔY| > 20px`

### 5.2 排版规则

- 端口标签沿链路走向呈**阶梯状错位分布**（纯文本模式）或**轴向旋转对齐**（图形渲染模式）
- 旋转角度 θ = `arctan(ΔY / ΔX)`，标签文字与链路平行
- 源端口标签位于链路前 1/3 段，目的端口标签位于链路后 1/3 段
- 标签与线条之间保持最小 `6px` 垂直间距（沿法线方向）
- 当链路角度为 45° 时，标签呈标准阶梯状；其他角度按实际计算旋转

### 5.3 ASCII 示意图（纯文本降级方案）

```TEXT
       [ 对角模式：阶梯错位 / 轴向对齐 ]

          'A设备'
               \
                \  <-- 上段斜链路（源端段）
                 \
                  G1/0/1  <-- 源端口 (斜排/阶梯内嵌)
                       \
                        \  <-- 中段斜链路 (物理连接)
                         \
                          G1/0/1  <-- 目的端口 (斜排/阶梯内嵌)
                               \
                                \  <-- 下段斜链路（目的端段）
                                 \
                                  'B设备'

    * 端口标签沿链路走向呈阶梯状分布
    * 强制开启字体描边/阴影，避免与斜线重叠导致识别困难
```

### 5.4 视觉要求

| 属性 | 值 |
| :--- | :--- |
| 字体方向（图形模式） | `transform: rotate(θ)`，θ = arctan(ΔY/ΔX) |
| 字体方向（文本模式） | 阶梯错位，每行缩进跟随斜率 |
| 旋转中心 | `transform-origin: left center`（标签左中点贴合链路） |
| 字体描边 | `-webkit-text-stroke: 1.5px #FFFFFF`（斜向加粗描边） |
| 文字阴影 | `text-shadow: 0 0 4px rgba(255,255,255,1), 0 0 8px rgba(255,255,255,0.6)` |
| 标签与线条法线间距 | ≥ `6px` |
| 标签字号 | `12px`（跟随画布缩放） |
| 标签颜色 | `#333333` |
| 避让规则 | 标签文字包围盒与链路线条不得重叠，重叠时自动沿法线偏移 |

## 六、前端实现技术要求

### 6.1 渲染引擎适配

| 渲染方式 | 适用场景 | 端口标签实现方案 |
| :--- | :--- | :--- |
| **SVG** | 主画布渲染（推荐） | `<text>` 元素 + `transform="rotate(θ, x, y)"` |
| **Canvas** | 高性能大图 | `ctx.save()` → `ctx.translate()` → `ctx.rotate()` → `ctx.fillText()` → `ctx.restore()` |
| **HTML/CSS** | 浮动标签层 | `position: absolute` + `transform: rotate(θ)` |
| **纯文本导出** | 日志/复制/导出 | ASCII 阶梯排列，无旋转 |

### 6.2 角度计算逻辑

```javascript
/**
 * 计算链路角度（用于斜向模式标签旋转）
 * @param {number} x1 - 源设备中心X
 * @param {number} y1 - 源设备中心Y
 * @param {number} x2 - 目的设备中心X
 * @param {number} y2 - 目的设备中心Y
 * @returns {number} 旋转角度（度）
 */
function getLinkAngle(x1, y1, x2, y2) {
    const dx = x2 - x1;
    const dy = y2 - y1;
    let angle = Math.atan2(dy, dx) * (180 / Math.PI);

    // 保证文字始终正向可读（不倒置）
    if (angle > 90 || angle < -90) {
        angle += 180;
    }
    return angle;
}
```

### 6.3 模式判定逻辑

```javascript
/**
 * 判定链路排列模式
 * @returns {'vertical' | 'horizontal' | 'diagonal'}
 */
function getLinkMode(x1, y1, x2, y2, threshold = 20) {
    const dx = Math.abs(x2 - x1);
    const dy = Math.abs(y2 - y1);

    if (dx <= threshold) return 'vertical';      // 模式A
    if (dy <= threshold) return 'horizontal';    // 模式B
    return 'diagonal';                           // 模式C
}
```

### 6.4 字体描边统一实现

```css
/* 所有端口标签通用样式 */
.port-label {
    font-size: 12px;
    color: #333333;
    font-family: 'Consolas', 'Monaco', 'Courier New', monospace;
    -webkit-text-stroke: 1px #FFFFFF;
    text-shadow: 0 0 3px rgba(255, 255, 255, 0.9);
    paint-order: stroke fill;  /* 确保描边在文字下层，不遮盖笔画 */
    user-select: none;
    pointer-events: none;      /* 标签不拦截鼠标事件 */
}

/* 斜向模式加强描边 */
.port-label--diagonal {
    -webkit-text-stroke: 1.5px #FFFFFF;
    text-shadow: 0 0 4px rgba(255,255,255,1),
                 0 0 8px rgba(255,255,255,0.6);
}
```

### 6.5 SVG 实现示例（对角模式）

```html
<svg width="400" height="300">
  <!-- 链路线条 -->
  <line x1="80" y1="40" x2="320" y2="260"
        stroke="#555" stroke-width="2" />

  <!-- 源端口标签（旋转对齐） -->
  <text x="140" y="105"
        class="port-label port-label--diagonal"
        transform="rotate(42.5, 140, 105)">
    G1/0/1
  </text>

  <!-- 目的端口标签（旋转对齐） -->
  <text x="250" y="205"
        class="port-label port-label--diagonal"
        transform="rotate(42.5, 250, 205)">
    G1/0/1
  </text>
</svg>
```

## 七、降级方案：纯文本导出

当用户执行「复制拓扑」「导出文本」「日志记录」等操作时，无法使用 CSS/SVG 渲染，需降级为纯 ASCII 文本。

### 7.1 降级规则

| 图形模式 | 纯文本降级策略 |
| :--- | :--- |
| 垂直 (Vertical Stacked) | 端口字符逐行堆叠，用 `\|` 表示链路 |
| 水平 (Horizontal Inline) | 端口单行排列，用 `---` 和 `===` 表示链路 |
| 对角 (Diagonal Staggered) | 端口阶梯错位，用 `\` 或 `/` 表示链路 |

### 7.2 导出格式模板

```TEXT
========================================
拓扑链路信息
========================================
模式：{Vertical Stacked | Horizontal Inline | Diagonal Staggered}
源设备：{设备名称}
源端口：{端口名称}
链路类型：{物理连接}
目的端口：{端口名称}
目的设备：{设备名称}
========================================
```

## 十、拓扑图设备自动布放规则

### 10.1 基本原则

1. 拓扑图设备根据**设备数量及设备之间的连接关系**自动计算布放区域。
2. 设备布放应充分利用拓扑图画布的可用分辨率。
3. 同一层级中的设备按照从左至右顺序排列。
4. 当设备数量较多，且存在一组设备共同连接至另一组设备时，应自动划分为上下区域。
5. 上下区域中的设备分别进行等分布放。
6. 本规则用于确定设备在拓扑图中的初始位置；设备位置变化后，链路端口展示规则仍根据设备实际坐标进行判定。

### 10.2 单设备布放

当拓扑图中只有 **1 台设备**时：

- 该设备占据拓扑图全部可用分辨率范围的中心区域。
- 设备作为当前拓扑图的唯一核心节点展示。

```TEXT
┌──────────────────────────────┐
│                              │
│                              │
│           设备1              │
│                              │
│                              │
└──────────────────────────────┘
```

### 10.3 双设备布放

当拓扑图中有 **2 台设备**时：

- 拓扑图横向划分为 2 个区域。
- 设备1位于左侧区域。
- 设备2位于右侧区域。

```TEXT
┌──────────────┬──────────────┐
│              │              │
│    设备1      │    设备2      │
│              │              │
└──────────────┴──────────────┘
```

### 10.4 三设备布放

当拓扑图中有 **3 台设备**时：

- 拓扑图横向划分为 3 个区域。
- 设备1位于左侧。
- 设备2位于中间。
- 设备3位于右侧。

```TEXT
┌──────────┬──────────┬──────────┐
│          │          │          │
│  设备1    │  设备2    │  设备3    │
│          │          │          │
└──────────┴──────────┴──────────┘
```

### 10.5 四设备布放

当拓扑图中有 **4 台设备**时：

- 拓扑图横向划分为 4 个区域。
- 从左至右依次布放：
  - 设备1：左侧
  - 设备2：中左侧
  - 设备3：中右侧
  - 设备4：右侧

```TEXT
┌───────┬───────┬───────┬───────┐
│       │       │       │       │
│ 设备1 │ 设备2 │ 设备3 │ 设备4 │
│       │       │       │       │
└───────┴───────┴───────┴───────┘
```

### 10.6 多设备上下分层布放

当设备数量大于等于 **5 台**时，如果存在以下连接关系：

- 前面一组设备作为上层设备；
- 后面一组设备同时连接至上层设备；

则拓扑图自动划分为**上下两个区域**。

#### 规则

- 上区域用于布放上层设备。
- 下区域用于布放下层设备。
- 每个区域根据该区域内设备数量进行横向等分。
- 同一层设备从左至右按照设备顺序排列。

### 10.7 五设备场景

当有 **5 台设备**，且设备3、设备4、设备5均连接设备1和设备2时：

**上区域：**

- 横向划分为 2 个区域。
- 左侧：设备1
- 右侧：设备2

**下区域：**

- 横向划分为 3 个区域。
- 左侧：设备3
- 中间：设备4
- 右侧：设备5

```TEXT
┌──────────────────────────────────────┐
│              上区域                   │
│                                      │
│         设备1          设备2          │
│                                      │
├──────────────────────────────────────┤
│              下区域                   │
│                                      │
│      设备3        设备4        设备5   │
│                                      │
└──────────────────────────────────────┘
```

### 10.8 六设备场景一

### 10.10 通用推导规则

上述规则继续适用于更多设备数量的场景。

当拓扑结构可以识别为：

```TEXT
上层设备集合
      ↓
下层设备集合
```

且下层多个设备均连接至上层设备集合时，自动采用上下分层布局。

设：

- 上层设备数量为 `N`
- 下层设备数量为 `M`

则：

1. 拓扑图划分为上下两个主要区域。
2. 上区域横向划分为 `N` 个等分区域。
3. 下区域横向划分为 `M` 个等分区域。
4. 每台设备放置于对应区域的中心位置。
5. 设备按照设备顺序从左至右排列。
6. 上下设备之间按照实际连接关系绘制链路。
7. 链路端口标签继续按照现有的垂直、水平、对角三种规则自动展示。

## 十一、拓扑图聚焦模式

### 11.1 功能说明

在网络拓扑图中增加**设备聚焦模式**。

用户点击拓扑图中的任意设备后，系统自动进入聚焦模式。

### 11.2 聚焦规则

点击某台设备后：

1. 自动隐藏拓扑图中除当前选中设备之外的其他设备。
2. 当前选中设备保留显示。
3. 当前设备相关的 **A端、B端拓扑图**保留显示。
4. 非当前设备相关的拓扑内容自动隐藏。
5. 聚焦后的拓扑图仅展示当前选中设备及其 A、B 端链路关系。

逻辑示意：

```TEXT
正常模式：

设备1 ─── 设备2 ─── 设备3 ─── 设备4


点击「设备2」后：

A端拓扑  ───  设备2  ───  B端拓扑
```

### 11.3 聚焦状态

进入聚焦模式后：

- 当前点击设备作为聚焦中心。
- 隐藏其他无关设备及无关链路。
- 保留当前设备对应的 A端、B端拓扑展示。
- 聚焦范围内的链路端口描述仍按照原有展示规范渲染，包括垂直、水平及对角链路模式。

### 11.4 取消聚焦

在聚焦模式下：

- 用户点击拓扑图空白区域。
- 系统自动取消聚焦模式。
- 恢复显示所有设备。
- 恢复显示所有设备之间原有的链路关系。
- 拓扑图恢复至进入聚焦模式之前的完整展示状态。

### 11.5 聚焦模式状态切换

状态定义：

```TEXT
默认状态
   │
   │ 点击设备
   ▼
聚焦状态
   │
   │ 点击空白区域
   ▼
默认状态
```

### 11.6 功能验收标准

- [ ] 点击任意设备后，可正常进入聚焦模式。
- [ ] 聚焦模式下，除当前设备外的无关设备自动隐藏。
- [ ] 当前设备的 A端、B端拓扑正常展示。
- [ ] 当前设备相关链路正常展示。
- [ ] 聚焦模式下端口描述展示规则不受影响。
- [ ] 点击拓扑图空白区域后，自动退出聚焦模式。
- [ ] 退出聚焦模式后，所有设备及链路恢复。
- [ ] 多次进入和退出聚焦模式，不出现设备残留、链路残留或重复渲染。
