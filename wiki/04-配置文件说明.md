# 04-配置文件说明

全部配置位于程序目录 `config/` 下，共 4 个 YAML 文件。除 `core.yaml` 为只读系统级配置外，其余均可读写；带中文注释，手工编辑请保持格式。

---

## 1. core.yaml（系统级，只读）

框架核心参数，首次启动生成。`jwt.secret_key` 随机生成并固定，每次重启保持不变（因此重启后旧 Token 仍有效）。

```yaml
# ==================================================
# NetCore Framework 系统核心配置（只读）
# ==================================================
# 修改此文件需要重启程序生效。
# jwt.secret_key 首次创建时自动生成，请勿手动修改。

server:
  host: "0.0.0.0"          # 监听地址；0.0.0.0 表示监听全部网卡
  port: 8080               # 监听端口（被占用时自动顺延 +1 ~ +20）

jwt:
  secret_key: "%s"         # JWT 签名密钥（HS256），首次创建时随机生成
  expire_minutes: 1440     # Token 有效期（分钟），默认 24 小时
```

### server 段

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| host | string | "0.0.0.0" | 监听地址。`0.0.0.0`=全部网卡；`127.0.0.1`=仅本机 |
| port | int | 8080 | 监听端口。被占用时自动顺延 +1~+20，以控制台打印为准 |

### jwt 段

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| secret_key | string | 随机生成 | JWT HS256 签名密钥。首次创建配置时随机生成并固定。重启不失效 |
| expire_minutes | int | 1440 | Token 有效期（分钟）。默认 24 小时。心跳可续期 |

**安全说明**：`secret_key` 泄露等同于所有用户会话被接管。请勿提交到版本控制。

## 2. user_config.yaml（用户配置，可读写）

用户可修改的全部配置。框架启动时自动迁移旧版本的段落（如 logging/notify/https 从 core.yaml 迁出）。

### system 段

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| name | string | "" | 自定义软件名称，空则显示内置值（NetCore Framework） |
| version | string | "" | 自定义版本号，空则显示内置版本 |
| auto_logout_minutes | int | 5 | 空闲自动退出分钟数。0=关闭自动退出 |
| timezone | string | Asia/Shanghai | IANA 时区名。全站历史时间显示都按它换算 |
| auto_update_timezone | bool | true | 每次登录用浏览器时区覆盖 timezone |
| default_page_size | int | 10 | 表格组件默认每页显示条数（1~100），前端 nc-table 自动读取 |

```yaml
system:
  name: ""
  version: ""
  auto_logout_minutes: 5
  timezone: "Asia/Shanghai"
  auto_update_timezone: true
  default_page_size: 10
```

### auth 段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| username | string | 固定 admin（暂不支持多用户） |
| password_hash | string | PBKDF2-SHA256 哈希，勿手填。为空/损坏时框架用默认密码重建 |
| password_plain | string | **一次性字段**：手动添加后重启，框架重置哈希并自删该字段 |
| totp_enabled | bool | TOTP 双因素开关 |
| totp_secret | string | TOTP 密钥（加密存储） |
| pending_totp_secret | string | TOTP 绑定流程中的待验证密钥（加密暂存） |
| last_login_time | string | 最近登录时间（ISO UTC） |
| last_login_ip | string | 最近登录 IP |

```yaml
auth:
  username: admin
  password_hash: "pbkdf2_sha256$600000$..."
  totp_enabled: false
  totp_secret: ""
  last_login_time: "2026-08-26T07:36:57.569Z"
  last_login_ip: "127.0.0.1"
```

**修改密码**：手动添加 `auth.password_plain: "新密码"` → 重启 → 框架重置哈希并删除该字段 → 再次启动生效。默认密码 `Admin@123!`。

### plugins 段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| detected | list[string] | 每次启动自动扫描写入的全部插件名（仅记录，不影响加载） |
| disabled | list[string] | 禁用列表。列入的插件不加载、不挂路由、不注册菜单 |

```yaml
plugins:
  detected:
    - wiki_docs
    - my_plugin
  disabled:
    - wiki_docs
```

### logging 段

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| level | string | INFO | 日志级别：DEBUG/INFO/WARNING/ERROR。可在日志中心热切换 |
| file | string | data/logs/ | **仅作路径说明**（目录语义）；实际按天命名为 `data/logs/YYYYMMDD-netcore.log` |
| max_bytes | int | 10485760 | 单文件最大字节（10MB），超出后按 .1/.2 后缀滚动 |
| backup_count | int | 30 | 保留轮转文件个数 |
| audit_log_retention_days | int | 60 | 审计日志保留天数，启动时自动清理。0/负数=关闭自动清理 |

```yaml
logging:
  level: INFO
  file: "data/logs/"
  max_bytes: 10485760
  backup_count: 30
  audit_log_retention_days: 60
```

**日志文件位置**：
- 运行日志：`logs/YYYYMMDD-netcore.log`（按天 + 大小滚动）
- 审计日志：`data/logs/audit/audit-YYYYMMDD.log`（按天 JSONL）

### https 段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| enabled | bool | HTTPS 总开关。默认 true（自签名证书） |
| cert_content | string | 自定义证书 PEM 文本。空=使用自签名 |
| key_content | string | 私钥 PEM 文本。空=使用自签名 |
| auto_redirect | bool | HTTP→HTTPS 反向协议跳转开关 |
| redirect_port | int | 跳转监听端口。空=主端口+1 |
| domain | string | 证书 SAN 显式地址列表（逗号分隔）。空=枚举本机非回环网卡 IP |

```yaml
https:
  enabled: true
  cert_content: ""
  key_content: ""
  auto_redirect: true
  redirect_port: 8081
  domain: ""
```

### security 段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| enable_docs | bool | 是否开放 Swagger `/docs` 与 `/openapi.json`。默认 false |
| trusted_proxies | list[string] | 可信反代 IP 列表。仅这些来源的 X-Forwarded-For 被信任用于审计 IP |

```yaml
security:
  enable_docs: false
  trusted_proxies: []
```

### notify 段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| rate_limit.min_interval_seconds | int | 全局通知最小发送间隔（秒）。默认 60 |

```yaml
notify:
  rate_limit:
    min_interval_seconds: 60
```

## 3. security.yaml（安全策略，可读写）

### failure_policy 段

控制登录失败后的自动封禁行为。

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| max_failures | int | 5 | 同一 IP 在重置间隔内连续失败达到该值即自动拉黑 |
| block_minutes | int | 10 | 自动封禁的持续时间（分钟） |
| reset_interval_minutes | int | 30 | 超过该间隔未再失败，计数清零重新累计 |

```yaml
failure_policy:
  max_failures: 5
  block_minutes: 10
  reset_interval_minutes: 30
```

### whitelist 段

白名单条目列表。命中白名单的 IP 免失败锁定计数。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ip | string | IP 地址或 CIDR（如 `192.168.1.100`、`10.0.0.0/8`） |
| note | string | 说明（如「管理员办公 IP」） |
| expires_at | string/null | 有效期（ISO UTC）。null/空=永久 |

```yaml
whitelist:
  - ip: "127.0.0.1"
    note: "系统初始化-本地管理通道"
    expires_at: null
  - ip: "10.0.0.0/8"
    note: "办公网段"
    expires_at: "2026-12-31T23:59:59Z"
```

**回环地址特殊策略**：`127.0.0.1` 与 `::1` 仅在**首次生成 security.yaml 时**自动写入；之后框架不再自动增删。

### blacklist 段

黑名单条目列表。命中且在封禁期内的 IP 返回 404。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ip | string | IP 地址或 CIDR |
| block_until | string/null | 到期时间（ISO UTC）。null=永久封禁 |
| reason | string | 封禁原因（如「连续5次失败」） |
| note | string | 说明 |
| fail_count | int | 累计失败次数 |

```yaml
blacklist:
  - ip: "203.0.113.45"
    block_until: "2026-08-26T10:30:00Z"
    reason: "连续5次失败"
    note: ""
    fail_count: 5
  - ip: "198.51.100.0/24"
    block_until: null
    reason: "手动拉黑"
    note: "恶意扫描"
    fail_count: 0
```

修改后即时生效，无需重启。检查顺序：白名单 → 黑名单（封禁期内 404）→ 正常登录。

## 4. notify.yaml（通知渠道，敏感字段加密）

每个渠道一个顶级键，公共字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| enabled | bool | 渠道开关 |
| template | string | 消息模板 ID（Go template 语法），默认 default |
| priority | string | 优先级标记 |

### email 渠道

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| smtp_host | string | - | SMTP 服务器地址 |
| smtp_port | int | 465 | SMTP 端口 |
| smtp_ssl | bool | true | 是否使用 SSL |
| username | string | - | SMTP 登录用户名 |
| password | string | - | SMTP 登录密码（AES-256-GCM 加密存储） |
| sender_name | string | NetCore Framework | 发件人显示名 |
| default_recipients | list[string] | [] | 默认收件人列表 |

```yaml
email:
  enabled: false
  smtp_host: "smtp.gmail.com"
  smtp_port: 465
  smtp_ssl: true
  username: "you@gmail.com"
  password: "加密后的密码"
  sender_name: "NetCore Framework"
  default_recipients:
    - "admin@example.com"
  template: default
  priority: normal
```

### wechat_work 渠道（企业微信）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| webhook_url | string | Webhook URL（加密存储） |

消息格式：Markdown。

```yaml
wechat_work:
  enabled: false
  webhook_url: "加密后的URL"
  template: default
  priority: normal
```

### dingtalk 渠道（钉钉）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| webhook_url | string | Webhook URL（加密存储） |
| secret | string | 加签密钥（加密存储）。框架自动计算签名 |

消息格式：Text。

```yaml
dingtalk:
  enabled: false
  webhook_url: "加密后的URL"
  secret: "加密后的密钥"
  template: default
  priority: normal
```

### feishu 渠道（飞书）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| webhook_url | string | Webhook URL（加密存储） |

消息格式：Text。

```yaml
feishu:
  enabled: false
  webhook_url: "加密后的URL"
  template: default
  priority: normal
```

### 消息模板

使用 Go template 语法，上下文变量：

| 变量 | 说明 |
| --- | --- |
| `{{.Title}}` | 消息标题 |
| `{{.Content}}` | 消息正文 |
| `{{.Time}}` | 时间（已按系统时区格式化 `YYYY-MM-DD HH:MM:SS`） |
| `{{.其他字段}}` | 调用方传入的业务字段 |

```yaml
templates:
  default:
    title: "[{{.Title}}] NetCore Framework 通知"
    body: |
      时间：{{.Time}}
      内容：{{.Content}}
  security_alert:
    title: "安全告警"
    body: |
      [{{.Time}}] {{.Title}}
      {{.Content}}
```

### 频率限制

同一渠道最小发送间隔默认 60 秒，可在 `user_config.yaml → notify.rate_limit.min_interval_seconds` 调整。

> Windows 平台时区换算依赖 `tzdata==2026.3`（已锁定在 requirements.txt，打包版自带）。
