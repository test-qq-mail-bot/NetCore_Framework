# 01 - 快速开始

本文档帮助你以最短路径把 NetCore Framework 跑起来，并熟悉 Web 管理界面。
阅读对象：实施人员、运维人员、二次开发工程师。

---

## 1. 框架概述

NetCore Framework 是一款**轻量级、插件化的通用后端底层框架**。框架本身不包含任何业务功能，所有能力（如「数通配置卫士」）均以独立插件形式接入。核心特性：

- 微核心 + 插件化架构，按需加载、故障隔离
- 双因素认证（密码 / 密码 + TOTP）
- 统一加密（AES-256-GCM）、通知管理、审计日志
- 配置驱动、零数据库（数据存于配置文件）
- 插件热重启（不停服）
- 响应式 Web 管理界面，单文件可执行（复制即用）
- 内置完整文档（`wiki/`）

---

## 2. 环境要求

| 使用方式 | 要求 |
|----------|------|
| **直接运行可执行文件（推荐客户）** | Windows / Linux x86-64；无需安装 Python |
| **开发模式（源码运行）** | Python 3.10+，依赖见 `requirements.txt` |

---

## 3. 方式一：直接运行可执行文件（推荐）

1. 获取 `netcore-framework`（Windows 为 `netcore-framework.exe`，Linux 为同名二进制）。
2. 将其放在**有写入权限**的目录（程序会在同级目录自动创建 `config/`、`data/`、`plugins/`、`frontend/`、`wiki/`）。
3. 双击运行（Linux 用 `./netcore-framework`）。
4. 程序监听 `0.0.0.0:8080`。**若 8080 被占用，会自动顺延到下一个可用端口**，并在控制台明确提示实际端口与访问地址，请按控制台提示打开。
5. 浏览器访问 `http://<服务器IP>:<实际端口>/`，进入登录页。
6. 使用初始账号登录：
   - 用户名：`admin`
   - 密码：`Admin@123!`
   - 首次使用默认密码会显示提示，建议登录后尽快修改（通过 `系统设置 → 安全策略` 或重置密码流程）。

> 注意：登录页**不会预填账号**，每次打开都需手动输入；关闭页面后再次打开也需重新登录（不记忆会话）。

---

## 4. 方式二：开发模式（源码运行）

```bash
# 1. 创建并激活虚拟环境（示例）
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python main.py
```

开发模式同样会自动创建目录与默认配置，端口冲突时也会自动顺延。

---

## 5. 首次运行做了什么

首次启动时框架会：

1. 检查运行目录写入权限，无权限则直接报错退出（保证环境一致）。
2. 自动生成 `config/core.yaml`（只读，含服务端口、JWT 密钥、加密密钥、日志、会话、通知频率限制）。
3. 自动生成 `config/user_config.yaml`（可读写，含密码哈希、TOTP、插件配置 `plugins.detected`（**每次启动自动重新扫描 `plugins/` 并写入全部检测到的插件**）与 `plugins.disabled` 黑名单、系统名称/版本）。
4. 自动生成 `config/security.yaml`（可读写，含 IP 黑白名单、登录失败策略）。
5. 自动生成 `config/notify.yaml`（可读写，含通知渠道配置与消息模板）。
6. 扫描并加载 `plugins/` 下所有已启用插件（如 `wiki_docs`、`netconfig_guardian`）。
7. 提取前端资源到运行目录，启动 Web 服务。

## 6. Web 管理界面导览

界面为左右分栏：左侧**可折叠菜单栏**，右侧**内容区**（顶部有「返回」按钮与当前用户、「退出」）。

### 6.1 菜单结构（默认仅显示一级，点击展开二级）

```
系统概览                      ← 系统名称 / 版本 / Python / 平台 / 运行时长（即“系统信息”模块）
系统设置
├── 安全策略                  ← 失败策略、白名单、黑名单
├── 通知管理                  ← 渠道状态、测试、编辑配置
├── 日志中心                  ← 日志级别调整 + 登录/审计日志查询/导出/清理
└── 插件管理                  ← 插件列表、热重启
数通配置卫士（示例插件）
├── 仪表盘
├── 设备管理
├── 任务管理
├── 变更历史
├── 运行日志
├── 驱动管理
└── 插件设置
使用文档                      ← 内置 wiki（见 00-README.md 文档索引）
```

> **菜单交互说明**：
> - 一级菜单默认只显示标题；点击**有子菜单的一级菜单**（如「系统设置」），会在其下方**展开/收起二级菜单**，而不会跳转；点击**叶子菜单**（如「系统概览」「安全策略」）则进入对应页面。
> - 点击左上角「汉堡」按钮可**折叠/展开**整个侧边栏：展开时显示「图标 + 文字」，折叠时仅显示图标。
> - 菜单图标均为内置线性 SVG（非 emoji），离线可用。

### 6.2 系统概览（系统信息）

进入「系统概览」即可查看：系统名称、版本、Python 版本、运行平台、运行时长、已加载插件数。该页面即项目书要求的「系统信息」模块。
