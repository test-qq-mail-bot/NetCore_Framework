# 05-插件开发指南

本文档覆盖插件开发全链路：目录结构、BasePlugin 契约、后端工具 API（加密/审计/日志/时间/配置）、前端注册表与组件、路由与菜单、模板工程、调试与发布。

---

## 1. 目录结构

```
plugins/<name>/
├── plugin.py            # 必需：入口，含 BasePlugin 子类
├── __init__.py          # 建议：空文件即可
├── frontend/            # 可选：页面脚本 *.js（自动注入 SPA）
│   ├── home.js
│   └── devices.js
├── data/                # 插件私有数据目录（升级时被保留）
│   ├── config.yaml      # 插件配置放这里（与数据库等运行时数据同级）
│   └── <name>.db        # SQLite 数据库等
└── templates/           # 可选：Go 模板文件（通知渲染等）
```

**配置文件位置**：插件的 `config.yaml` 放在 `data/` 目录下，与数据库等运行时数据同级。框架升级时 `data/` 整体被保留（跳过不覆盖），配置跨版本安全。

模板工程见仓库 `wiki/plugin_template/`（含最小可运行 plugin.py 与 config.yaml）。

## 2. BasePlugin 契约

继承 `plugins.base_plugin.BasePlugin`，实现四个抽象方法：

```python
from fastapi import APIRouter, Depends
from core.auth import get_current_user
from core.logger import get_logger
from core.audit import audit_log
from core.timeutil import utc_now_iso, now_local_str
from core.config_loader import get_user_config, save_user_config
from core.crypto_utils import CryptoUtils
from core.config_loader import get_encryption_key
from plugins.base_plugin import BasePlugin

logger = get_logger()

class Plugin(BasePlugin):
    def __init__(self, name: str, config: dict = None):
        super().__init__(name, config)
        # 插件自己的状态（连接池、缓存等）
        self._db = None

    def get_metadata(self) -> dict:
        """返回插件元信息（必填）"""
        return {
            "name": self.name,           # 与目录名一致
            "version": "20260826-V1",    # 遵循 日期-V序号
            "description": "插件说明",
            "author": "作者名"
        }

    def on_load(self) -> bool:
        """初始化插件，返回 True=成功 / False=失败（框架标记为 failed）

        可以做：建表、读配置、启动后台线程、连接外部服务等。
        失败不影响其他插件与核心功能。
        """
        try:
            # 示例：初始化 SQLite 数据库
            import sqlite3
            from pathlib import Path
            db_path = Path("data") / f"{self.name}.db"
            db_path.parent.mkdir(parents=True, exist_ok=True)
            self._db = sqlite3.connect(str(db_path))
            logger.info("插件 %s 数据库初始化完成", self.name)
            return True
        except Exception as exc:
            logger.error("插件 %s 初始化失败: %s", self.name, exc)
            return False

    def get_routes(self) -> APIRouter:
        """注册 API 路由（返回 APIRouter 或 None）

        路由统一加业务前缀 /<name>，数据接口必须挂 get_current_user 鉴权。
        """
        router = APIRouter(prefix=f"/{self.name}", tags=[self.name])

        @router.get("/items", dependencies=[Depends(get_current_user)])
        async def list_items():
            """获取列表（示例）"""
            return {"items": [], "total": 0}

        @router.post("/items", dependencies=[Depends(get_current_user)])
        async def create_item(body: dict):
            """创建条目（示例）"""
            audit_log("item_create", f"创建条目: {body.get('name', '')}", "success")
            return {"success": True}

        @router.get("/items/{item_id}", dependencies=[Depends(get_current_user)])
        async def get_item(item_id: int):
            """获取单条"""
            return {"id": item_id, "name": "示例"}

        @router.put("/items/{item_id}", dependencies=[Depends(get_current_user)])
        async def update_item(item_id: int, body: dict):
            """更新条目"""
            return {"success": True}

        @router.delete("/items/{item_id}", dependencies=[Depends(get_current_user)])
        async def delete_item(item_id: int):
            """删除条目"""
            audit_log("item_delete", f"删除条目: {item_id}", "success")
            return {"success": True}

        return router

    def get_menus(self) -> list:
        """注册菜单项（返回列表或空列表）

        菜单 id 与前端组件 id 对应；path 格式 /<plugin>/<page> 自动推导组件 id <plugin>_<page>。
        """
        return [
            {"id": f"{self.name}_home",      "label": "首页",      "path": f"/{self.name}/home",      "icon": "dashboard"},
            {"id": f"{self.name}_devices",   "label": "设备管理",  "path": f"/{self.name}/devices",   "icon": "guardian"},
        ]

    def on_unload(self):
        """优雅关闭（最长等待 10 秒由框架控制超时）

        可以做：停后台线程、关闭数据库连接、释放资源。
        """
        if self._db:
            try:
                self._db.close()
            except Exception:
                pass
```

## 3. 生命周期详解

| 阶段 | 框架行为 | 插件可用操作 |
| --- | --- | --- |
| 发现 | 扫描 `plugins/*/plugin.py` | - |
| 加载 | importlib 导入 → 实例化(name, config) → `on_load()` → 收集 routes/menus | 建表、读配置、起后台线程 |
| 挂载 | 启动期 `mount_routes` 全量挂到 FastAPI；运行期走 `mount_new_routes` 补挂 | - |
| 运行 | 请求经路由处理 | 使用框架提供的全部 API（见下文） |
| 禁用 | user_config.disabled 列表控制；实例卸载但已挂路由保留 | `on_unload()` 释放资源 |
| 重载 | 旧实例 `on_unload()`（带超时）→ reload 模块 → 重建实例 → 补挂路由 | 可在 `on_load()` 重建状态 |
| 卸载 | 关闭进程时逐个调用 `on_unload()` | 关闭连接、停线程 |

**故障隔离**：单插件 `on_load()` 抛异常或返回 False → 标记为 `failed`，不影响其他插件。

**路由语义**：Starlette 不支持运行期摘除已 include 的路由。禁用插件是生命周期语义（实例被卸载），已挂载的 API 路由会保留到下次重启。启用后由 `mount_new_routes` 补挂新路由。

## 4. 后端工具 API

框架为插件提供以下底层能力，均可直接 import 调用。

### 4.1 加密工具 core.crypto_utils

```python
from core.crypto_utils import CryptoUtils
```

| 方法 | 说明 | 参数 | 返回 |
| --- | --- | --- | --- |
| `generate_key()` | 生成随机 AES-256 密钥 | - | Base64 编码密钥字符串 |
| `encrypt(plaintext, key)` | AES-256-GCM 加密 | 明文字符串 + Base64 密钥 | Base64 密文（含 nonce+tag） |
| `decrypt(ciphertext, key)` | AES-256-GCM 解密 | Base64 密文 + Base64 密钥 | 明文字符串 |
| `hash_password(password)` | PBKDF2-SHA256 哈希 | 明文密码 | 格式 `pbkdf2_sha256$600000$盐$哈希` |
| `verify_password(password, hash)` | 校验密码 | 明文密码 + 哈希字符串 | True/False |

**密文格式**：`Base64( nonce[12] || ciphertext[N] || tag[16] )`，与前端 `aesgcm.js` 严格一致。

**使用场景**：
- 存储敏感数据（数据库密码、API Token）前先加密
- 与前端 AES 加密字段互通
- 密码哈希用于自定义登录逻辑

```python
# 示例：加密存储 API Token
from core.config_loader import get_encryption_key
key = get_encryption_key()
encrypted = CryptoUtils.encrypt("my-secret-api-token", key)
# 存入数据库...
# 读取后解密
decrypted = CryptoUtils.decrypt(encrypted, key)
```

### 4.2 审计日志 core.audit

```python
from core.audit import audit_log, query_audit, clean_audit
```

| 函数 | 说明 | 参数 |
| --- | --- | --- |
| `audit_log(action, detail, result, username)` | 写入一条审计记录 | action=操作类型, detail=详情, result="success"/"failed", username=操作人(可选) |
| `query_audit(...)` | 分页查询审计日志 | page, size, ip, result, action, start_date, end_date, sort_by, sort_order |
| `clean_audit()` | 清空全部审计日志 | - |

**特性**：
- 自动填充时间戳（UTC 毫秒精度）、客户端 IP、用户名
- 线程安全（写入锁保证 JSONL 不交错）
- 存储格式：JSONL 按天切分 `data/logs/audit/audit-YYYYMMDD.log`

```python

# 示例：记录失败操作

# 示例：查询最近操作
```


### 4.4 时间工具 core.timeutil

```python
from core.timeutil import utc_now, utc_now_iso, utc_now_str, to_utc_str, configured_timezone, fmt_utc, now_local_str
```

| 函数 | 返回格式 | 用途 |
| --- | --- | --- |
| `utc_now()` | `datetime`（naive UTC） | 入库用 datetime 字段 |
| `utc_now_iso()` | `2026-08-26T15:36:57.123456` | last_run/started_at 等 ISO 字段 |
| `utc_now_str()` | `2026-08-26 15:36:57` | 与 SQLite datetime('now') 同格式 |
| `to_utc_str(dt)` | `2026-08-26 15:36:57` | 本地时间转 UTC 字符串（带时区自动换算） |
| `configured_timezone()` | `Asia/Shanghai` | 读取用户配置时区 |
| `fmt_utc(ts)` | `2026-08-26 23:36:57` | UTC 时间戳 → 配置时区显示格式 |
| `now_local_str()` | `2026-08-26 23:36:57` | 当前时刻按配置时区格式化（通知模板等） |

**核心规范**：**入库一律 UTC，展示交给前端 `NC.fmtTime`**。插件层不要用 `datetime.now()`（本地时间）写库，统一用本模块的 UTC 函数。

```python
from core.timeutil import utc_now_iso, utc_now_str, fmt_utc, now_local_str

# 入库
record["created_at"] = utc_now_iso()       # ISO 格式
record["last_run"] = utc_now_str()          # 常规格式

# 通知模板中使用
notify.send(title="备份完成", content=f"时间: {now_local_str()}")
```

```python
tz = get_user_config().get("system", {}).get("timezone", "Asia/Shanghai")

    cfg.setdefault("plugins", {}).setdefault("my_settings", {})["last_run"] = utc_now_iso()
update_user_config(_add_plugin_setting)
```

## 5. 前端开发

### 5.1 文件放置

页面脚本放 `plugins/<name>/frontend/*.js`（仅顶层目录），经框架自动发现并注入。

注入流程：
1. 登录后调用 `GET /api/plugins/frontend-manifest` 获取清单
2. 以 `<script src="/plugin-assets/<name>/<file>.js?v=<mtime>">` 动态注入
3. 脚本内调用 `NC.registerPage()` 注册页面组件

**免认证**：`/plugin-assets/*` 不需要 Bearer Token（脚本本身不含数据，数据一律走带鉴权的 API）。

### 5.2 页面注册

```javascript
window.NC.registerPage('<plugin>_<page>', {
    template: `...`,
    data() { return { items: [], loading: false }; },
    computed: { /* ... */ },
    methods: { /* ... */ },
    mounted() { /* 初始化加载数据 */ }
}, '页面标题');
```

**组件 id 约定**：
- 路由 `/<plugin>/<page>` → 组件 id `<plugin>_<page>`
- 特殊映射走 `window.NC.PATH_MAP`（仅约定推导失败时使用）
- 组件 id 必须与菜单 `id` 一致

### 5.4 HTTP 请求

```javascript
// GET 请求
const res = await http.get('/api/my_plugin/items');
console.log(res.data);  // { items: [...], total: 10 }

// POST 请求
const res = await http.post('/api/my_plugin/items', {
    name: '新条目',
    config: { key: 'value' }
});

// PUT 请求
await http.put(`/api/my_plugin/items/${id}`, { name: '更新' });

// DELETE 请求（注意：IP 删除类接口可能用 query 参数）
await http.delete(`/api/my_plugin/items/${id}`);

// 二进制下载（如导出文件）
const res = await http.get('/api/my_plugin/export', { responseType: 'blob' });
const url = URL.createObjectURL(res.data);
const a = document.createElement('a');
a.href = url; a.download = 'export.csv'; a.click();
URL.revokeObjectURL(url);
```

**特性**：
- 自动在 Header 加 `Authorization: Bearer <token>`
- 401 响应自动清除 Token 并触发 `nc-unauthorized` 事件回登录视图
- DEBUG 级别时自动在控制台输出请求/响应日志

### 5.5 时间格式化

**所有时间显示必须用 `NC.fmtTime`**，不要用 `new Date().toLocaleString()` 或其他方式（口径全站统一）。

```javascript
// 正确：UTC 入库 → fmtTime 显示
<span>{{ NC.fmtTime(item.created_at) }}</span>

// 在组件 methods 中
methods: {
    fmtTime(v) {
        return (window.NC && window.NC.fmtTime) ? window.NC.fmtTime(v) : String(v);
    }
}
```

### 5.6 统一表格组件 nc-table

声明式列定义 → 自动生成表头排序/筛选 + 斑马纹 + 空态 + 分页。

#### 快速开始（推荐写法）

**第一步：在 data() 中声明分页变量**

```javascript
data() {
    return {
        page: 1,
        pageSize: (window.NC && window.NC.defaultPageSize) || 10,
        list: []
    };
}
```

> `NC.defaultPageSize` 来自系统设置中「表单默认翻页数据」，登录后自动加载。若未加载完成则回退到 10。

**第二步：在模板中使用 nc-table**

```html
<nc-table :data="list" :columns="cols" client-paged
          :page="page" :page-size="pageSize" :page-sizes="[5,10,20,50]"
          @page-change="(p) => { page = p; }"
          @size-change="(s) => { pageSize = s; page = 1; }">
    <template #col-status="{ row }">
        <el-tag :type="row.status === 'ok' ? 'success' : 'danger'">
            {{ row.status === 'ok' ? '正常' : '异常' }}
        </el-tag>
    </template>
</nc-table>
```

**第三步：定义 columns**

```javascript
computed: {
    cols() {
        return [
```

#### 完整页面模板

```html
<template>
    <div class="nc-page">
        <div class="nc-section">
            <div class="nc-table-card">
                <div class="nc-toolbar">
                    <h2 class="nc-section-title">数据列表</h2>
                    <el-button type="primary" size="small" @click="load">刷新</el-button>
                </div>
                <nc-table :data="list" :columns="cols" client-paged :loading="loading"
                          :page="page" :page-size="pageSize" :page-sizes="[5,10,20,50]"
                          @page-change="(p) => { page = p; }"
                          @size-change="(s) => { pageSize = s; page = 1; }">
                    <template #col-ops="{ row }">
                        <el-button size="small" type="danger" @click="del(row)">删除</el-button>
                    </template>
                </nc-table>
            </div>
        </div>
    </div>
</template>

<script>
export default {
    data() {
        return {
            page: 1,
            pageSize: (window.NC && window.NC.defaultPageSize) || 10,
            list: [],
            loading: false
        };
    },
    computed: {
        cols() {
            return [
                { label: '名称', prop: 'name', minWidth: 120, sortable: true, filterable: true },
                { label: '操作', width: 150, slotName: 'col-ops' },
            ];
        }
    },
    mounted() { this.load(); },
    methods: {
        async load() {
            this.loading = true;
            try {
                const r = await http.get('/api/xxx/list');
                this.list = r.data || [];
            } finally { this.loading = false; }
        },
        async del(row) {
            await http.post('/api/xxx/delete', { id: row.id });
            this.load();
        }
    }
};
</script>
```

#### Props 完整参考

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| columns | Array | [] | 列定义（见下方 columns 字段表） |

| backend | Boolean | false | 后端分页模式（排序/筛选/分页由外部控制） |

### 5.7 通用页面模块结构

每个页面应遵循以下 div 层级结构（框架自动注入 `nc-module` / `data-module` class 用于调试定位）：

```html
<template>
  <div class="nc-page">
    <div class="nc-section">
      <h2 class="nc-section-title">模块标题</h2>
      <div class="nc-table-card">
        <!-- 工具栏 -->
        <div class="nc-toolbar">
          <el-button type="primary" @click="add">添加</el-button>
        </div>
        <!-- 表格 -->
        <nc-table :data="list" :columns="cols" client-paged
                  :page="page" :page-size="pageSize" :page-sizes="[5,10,20,50]"
                  @page-change="(p) => { page = p; }"
                  @size-change="(s) => { pageSize = s; page = 1; }">
          <template #col-ops="{ row }">
            <el-button size="small" type="danger" @click="del(row)">删除</el-button>
          </template>
        </nc-table>
      </div>
    </div>
  </div>
</template>

<script>
export default {
  data() {
    return {
      page: 1,
      pageSize: (window.NC && window.NC.defaultPageSize) || 10,
      list: []
    };
  }
};
</script>
```

**div 层级说明**：

| 层级 | class | 用途 |
| --- | --- | --- |
| 1 | `nc-page` | 页面根容器 |
| 2 | `nc-section` | 功能区块 |
| 3 | `nc-section-title` | 区块标题（h2） |
| 3 | `nc-table-card` | 表格卡片容器（带圆角/阴影） |
| 3 | `nc-form-card` | 表单卡片容器（同上，用于设置表单） |
| 4 | `nc-toolbar` | 按钮/筛选工具栏 |

**模块自动标识**：框架 `_injectModuleClass()` 在页面注册时自动为模板根元素注入 `nc-module nc-module-<id>` class 和 `data-module="<id>"` 属性，为页面内所有 `nc-card` 追加模块级 class。插件开发者无需手动添加。

## 7. 调试

### 7.1 日志排查

```bash
# 查看插件加载状态
grep "插件 <name>" logs/YYYYMMDD-netcore.log

# 查看 API 请求
# 日志级别设为 DEBUG 后，每个请求会输出方法/路径/状态码/耗时
```

### 7.2 前端调试

1. 浏览器 F12 打开控制台
2. `window.NC.PAGES` 查看已注册的页面组件
3. `NC_LOG_LEVEL = 'DEBUG'` 开启请求/响应日志
4. 查看 Network 面板确认 API 调用

### 7.3 常见问题排查

| 问题 | 排查 |
| --- | --- |
| 插件未加载 | 检查目录层级 `plugins/<name>/plugin.py` 是否正确 |
| 加载失败 | 查看日志中 `插件 <name> 加载失败` 的错误信息 |
| API 404 | 检查 `get_routes()` 是否返回了 APIRouter；插件管理页 route_count 是否为 0 |
| 页面空白 | 检查注册的组件 id 是否与菜单 id 一致 |
| 时间显示异常 | 确认使用 `NC.fmtTime()` 而非原生 JS 时间格式化 |

## 8. 发布

1. 独立 git 仓库只含源码（排除 `data/`、`__pycache__/`、`.venv/`）
2. 用户下载后放入 `plugins/` 即可（注意目录层级不要多套一层）
3. 主框架 requirements.txt 已含全部官方插件依赖；自研插件的新依赖需自行安装并在文档注明
4. 插件版本号遵循 `变动日期-V序号`，随插件仓库单独维护
