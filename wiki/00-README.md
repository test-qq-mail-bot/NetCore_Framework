# NetCore Framework 文档导航

NetCore Framework 是一款面向网络运维场景的插件化底层平台，采用 Python 3.13 + FastAPI + SQLite 后端与 Vue 3 + Element Plus 离线 SPA 前端，通过 PyInstaller 打包为单文件可执行程序，支持 Windows / Linux 双平台部署。

## 全局约定（贯穿全部文档）

1. **时间口径**：所有时间入库统一为 UTC；界面显示 = UTC + `user_config.yaml` 的 `timezone` 换算，格式 `YYYY-MM-DD HH:MM:SS`，不含时区后缀与毫秒。审计导出同口径（字段名 `timestamp`）。详见《06-程序逻辑与架构》第 3 节。
2. **图标规范**：全站图标一律 SVG，不使用 emoji 或 PNG。
3. **版本号**：`变动日期-V序号`（如 `20260826-V6`），谁改动谁升版，详见《08-构建与交付》第 4 节。
4. **禁止事项**：不在源码中使用 emoji；不自行创建文档未提及的目录；不直接 push 到 GitHub。

## 程序仓库结构速查

```
NetCore-Framework/
├── core/                  # 框架核心（路由、鉴权、审计、通知、会话、HTTPS、插件管理、配置加载、时间基准）
├── plugins/               # 插件目录（基类 base_plugin.py + 业务插件）
├── frontend/              # 前端静态资源（JS / CSS / HTML / favicon.svg）
├── wiki/                  # 内置文档集（本目录）
├── wiki/plugin_template/  # 插件模板工程（开发者参考）
├── tests/                 # pytest 测试
├── main.py                # 开发模式入口
├── build.py               # 单文件构建脚本
├── requirements.txt       # 运行时依赖（精确锁定）
├── requirements-dev.txt   # 构建期依赖（含 pytest / ruff）
└── .github/workflows/     # GitHub Actions CI
```
