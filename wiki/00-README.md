## 二、一句话上手

1. 把 `netcore-framework`（Linux）或 `netcore-framework.exe`（Windows）放到**有写入权限**的目录，双击运行。
2. 控制台会显示实际端口（默认 8080，被占用自动顺延）。
3. 浏览器打开 `http://<IP>:<端口>/`，用 `admin` / `Admin@123!` 登录。
4. 左侧菜单：**系统概览 / 系统设置 / 各业务插件 / 使用文档（wiki）**。

> 内置文档查看器（`/wiki/view/<文件名>`）仅读取本目录顶层 `.md` 文件，请勿将文档移入子目录。

## 三、设计理念速览

- **微核心 + 插件化**：框架不含业务逻辑，能力均为插件，增加 / 删除插件不影响其他模块。
- **零数据库**：数据存于配置文件与本地文件（SQLite）。
- **安全优先**：AES-256-GCM 加密、双因素认证（TOTP）、IP 黑白名单、审计日志。
- **开箱即用**：单文件可执行，复制即用；升级只需替换文件。
- **文档即代码**：内置完整 wiki，并提供空白插件模板。
- **禁用 Emoji**：代码、配置、日志、文档均不使用 Emoji；菜单图标为内置 SVG。
