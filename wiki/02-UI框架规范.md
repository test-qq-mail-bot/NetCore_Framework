# UI 框架规范（NetCore Framework）

> 适用版本：20260709-v16 起。本文定义前端统一设计系统与页面开发契约，所有框架原生页与插件页都应遵循，以保证一致性与"单页故障不影响其他界面"。

## 1. 设计令牌（Design Tokens）

所有颜色、圆角、阴影、间距均通过 CSS 变量定义，位于 `frontend/index.css` 的 `:root`。插件或主题可通过覆盖这些变量换肤，而无需改动组件代码。

| 变量 | 含义 | 默认值 |
|------|------|--------|
| `--nc-primary` | 主色（按钮、激活态） | `#2d8cf0` |
| `--nc-success` / `--nc-warning` / `--nc-danger` / `--nc-info` | 状态色 | 绿/橙/红/灰 |
| `--nc-bg` | 页面背景 | `#f5f7fa` |
| `--nc-surface` | 卡片/表面 | `#ffffff` |
| `--nc-border` / `--nc-border-light` | 边框 | `#e4e7ed` / `#ebeef5` |
| `--nc-text` / `--nc-text-secondary` / `--nc-text-placeholder` | 文字 | `#303133` 等 |
| `--nc-aside-bg` | 侧边栏背景（深色） | `#1f2d3d` |
| `--nc-radius` / `--nc-radius-sm` | 圆角 | `8px` / `6px` |
| `--nc-shadow` / `--nc-shadow-md` | 阴影 | 见源码 |
| `--nc-gap` | 标准间距 | `16px` |
| `--nc-header-h` | 头部高度 | `56px` |

## 2. 布局结构

```
.nc-layout
 ├─ .nc-aside      侧边栏（含 .nc-logo / .nc-resize-handle / 菜单 / .nc-aside-footer 版本号）
 └─ .nc-main
     ├─ .nc-header 头部（汉堡 / 返回 / 面包屑标题 / 实时时钟 / 用户名 / 退出）
     └─ .nc-content 内容区（包在 <nc-error-boundary> 内渲染当前页面）
```

## 3. 通用样式类（直接使用）

- `.nc-card`：白色卡片容器，自带圆角/阴影/内边距，内含 `<h3>` 作为区块标题。
- `.nc-page-title` / `.nc-muted`：页面标题与次要说明文字。
- 表单、表格、按钮统一使用 Element Plus 组件（已全局注册），无需额外样式。

## 4. 页面注册契约（核心）

每个页面是一个独立 JS 文件，通过运行地基 `frontend/ui/framework.js` 暴露的 `window.NC.registerPage(id, componentOptions, title)` 自注册：

```js
// frontend/pages/core/example.js
window.NC.registerPage('core_example', {
    template: `<div class="nc-card"><h3>示例</h3>...</div>`,
    data() { return { /* ... */ }; },
    methods: { /* ... */ },
    mounted() { /* 拉取数据 */ }
}, '示例页');
```

- `id`：全局唯一，且与 `frontend/app.js` 中 `resolvePageId(path)` 的映射一致（框架原生页用 `core_*` 前缀，插件页用 `<plugin>_*` 前缀）。
- `componentOptions`：标准 Vue3 选项式 API（`template` / `data` / `methods` / `computed` / `watch` / `mounted` 等）。
- 页面内使用全局 `http`（axios 实例，已带鉴权拦截器）、`this.$message`、Element Plus 组件，无需 `import` 或 `createApp`。

## 5. 共享工具（全局可用）

| 全局 | 说明 |
|------|------|
| `http` / `window.NC_HTTP` | axios 实例，自动附加 `Authorization` 头，401 自动回登录 |
| `window.NC_aesEncrypt(plain)` | AES-256-GCM 字段加密（与后端 `CryptoUtils` 兼容） |
| `window.NC_zhCn` | Element Plus 中文 locale（日期选择器等） |
| `window.NC_weekdayCn(dateStr)` | 返回"星期X"，用于有效期展示 |
| `window.NC_iconSvg(name)` / `window.NC_ICONS` | 内置线性 SVG 图标（dashboard/setting/security/bell/log/plugin/guardian/doc/chevron） |
| `window.NC_CRYPTO_KEY` / `window.NC_TOKEN` | 加密密钥 / 认证令牌（运行时由登录流程写入） |

## 6. 错误隔离（重要）

每个页面渲染都被 `<nc-error-boundary>` 包裹。若某页面在渲染期抛出异常，只会显示该页"模块加载失败"提示，**不影响其他页面与整体框架**。若某页面脚本本身无法解析（如语法错误），该页面不会被注册，访问时显示"页面未加载"，同样不会波及其他模块。

## 7. 插件自带 UI 规范（可选）

插件可以不使用本框架的设计令牌与基础组件，自行实现 UI 风格——只要在 `plugins/<name>/frontend/*.js` 中通过 `window.NC.registerPage` 提供符合契约的页面组件即可，框架仅负责装载与路由，不强制样式。
